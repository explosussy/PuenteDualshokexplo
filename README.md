# PuenteDualshokexplo
app de telefono y pc de codigo abierto que funciona como puente para conectar mandos (por ahora de ps4) a pc si no tienes bluethoot por medio de wi fi o usb


para ejecutar desde python requieres los siguientes componentes obligatorios:

===========
ViGEMbus
===========

desde la terminal:
pip install vgamepad
pip install cryptography
pip install psutil
